# Measurement spike (2026-10-21)

This folder is the frozen code and raw results behind [docs/SPIKE-RESULTS.md](../docs/SPIKE-RESULTS.md): boundary tiles (`tiles/`), browser and Node benchmarks (`bench-web/`), the workers-rs prototype (`worker/`), latency from the Philippines (`latency/`) and the Python data probes (`python/`). How to rerun each part is in that document's "Reproduce" section.

It is not part of the build or CI. Each script regenerates its own inputs, and large outputs are gitignored.
